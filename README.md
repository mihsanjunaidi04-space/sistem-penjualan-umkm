# Sistem Informasi Penjualan UMKM Berbasis Web

Aplikasi sistem informasi penjualan UMKM berbasis web yang terdiri dari frontend dan backend API.

## Tech Stack

### Frontend
- React
- Vite
- TypeScript
- Axios

### Backend
- Ruby on Rails 8.1.4 (API-only)
- Ruby 4.0.7
- SQLite 3
- RSpec Rails
